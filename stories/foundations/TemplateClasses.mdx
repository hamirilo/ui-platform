# テンプレート用クラス

Django テンプレートから「素の HTML + class」で使う部品の見本です。
定義は `tokens/classes.css`（`application-ui-kit/styles.css` に含まれる）。
ここに並ぶクラス名がパッケージの **公開契約** で、追加は MINOR、rename / 削除は MAJOR
（`decisions/adr-0007`）。

React コンポーネントの中ではこれらのクラスを書かず、対応するコンポーネントを使います。
見た目は 1:1 に揃えてあるので、テンプレートで描いた画面と React で描いた画面が並んでも差が出ません。

/>

- 色は Token（`var(--color-*)`）だけで書かれているので、`<html class="dark">` でも
  `[data-theme="dark"]` で Token を差し替える方式でも、そのまま暗くなります
- 利用側が同名のクラスを自前で定義している場合は、`styles.css` を読み込んだうえで
  **自前の定義を削除**してください。残すと読み込み順で自前が勝ち、何も変わりません
- 末尾にアイコンを置くときは `<svg>` を `<span>` で包みます（`:first-child` の判定のため）
